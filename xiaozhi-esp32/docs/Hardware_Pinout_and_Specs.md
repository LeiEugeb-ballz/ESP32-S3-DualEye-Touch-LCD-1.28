# DEVICE HARDWARE SPECIFICATION

* Board: Waveshare ESP32-S3 Dual 1.28-inch Round LCD (GC9A01 drivers)
* MCU: ESP32-S3 Dual-Core Xtensa LX7, 240MHz, 16MB Flash, 8MB PSRAM
* Displays: Dual 1.28-inch TFT LCD (240x240 each), GC9A01 SPI interface
* Display Function: Eye animatronics / emotion rendering / status UI
* Audio: Onboard I2S microphone (INMP441) and I2S DAC/Amp (MAX98357A / ES8311)
* Connectivity: 2.4 GHz Wi-Fi (802.11 b/g/n), Bluetooth 5 (LE)
